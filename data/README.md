# Dataset setup

Download the synthetic [Student Performance Dataset](https://www.kaggle.com/datasets/amar5693/student-performance-dataset) from Kaggle and place its CSV file in this directory if the notebook's automatic `kagglehub` download is unavailable.

The raw dataset is intentionally not redistributed in this repository. This keeps the source attribution explicit and avoids publishing third-party data without confirming its redistribution terms.
